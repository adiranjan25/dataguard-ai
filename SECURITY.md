# Security Policy

## Reporting

Please do not open a public issue for a suspected vulnerability. Before public launch, configure a private GitHub Security Advisory workflow and a security contact address in this file.

Never include credentials, secrets, production records, or sensitive personal data in bug reports.

## Data handling

The core scanner runs locally. Optional external AI providers may receive structured findings. The included OpenAI provider removes sampled raw values before transmission, but users remain responsible for organizational policy, contracts, and applicable privacy requirements.
