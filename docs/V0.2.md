# DataGuard AI v0.2

## Rule engine
Rules live under `rules:` in YAML. Supported types:
`not_null`, `unique`, `accepted_values`, `between`, `regex`, `max_null_pct`, `row_count_between`.

## DuckDB
```bash
pip install -e ".[duckdb]"
dataguard scan-duckdb analytics.duckdb --table customers --html-out report.html
```

## PostgreSQL
```bash
pip install -e ".[postgres]"
export DATAGUARD_POSTGRES_URL='postgresql+psycopg://user:pass@host/db'
dataguard scan-postgres --table public.customers --html-out report.html
```
The MVP reads the selected table into memory. Warehouse-scale pushdown profiling remains a roadmap item.

## Great Expectations
```bash
dataguard generate-gx customers.csv --out gx-expectations.json
```
The export is deliberately portable JSON rather than mutating an existing GX Data Context. Teams can review/version it before translating it into their GX Core project.

## GitHub Actions
`.github/workflows/dataguard.yml` demonstrates scanning checked-in synthetic/sample data and uploading JSON/HTML reports as workflow artifacts.
