# Public launch checklist

- [ ] Confirm GitHub repository name and PyPI package availability.
- [ ] Replace README placeholders with final repository URL.
- [ ] Add a real security contact or enable GitHub private vulnerability reporting.
- [ ] Run `pytest` and `ruff check src tests`.
- [ ] Run `dataguard demo`.
- [ ] Capture terminal screenshot/GIF for README.
- [ ] Create GitHub topics: data-quality, data-governance, data-engineering, dbt, pii, data-contracts.
- [ ] Publish GitHub Release `v0.1.0`.
- [ ] Publish package to TestPyPI first, then PyPI.
- [ ] Create 5–8 labeled `good first issue` tasks.
- [ ] Announce with a technical demo, not immigration framing.
- [ ] Preserve monthly GitHub/PyPI adoption evidence and independent references.
